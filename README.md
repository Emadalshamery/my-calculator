# my-calculator

A responsive, single-file scientific calculator built for Emadalshamery.

Features
- Single HTML file containing HTML, CSS, and JavaScript.
- Scientific functions: sin, cos, tan, asin, acos, atan, ln, log, sqrt, exp, power (^), factorial (!), percent (%).
- Constants: π and e.
- Keyboard support (numbers, operators, Enter to evaluate, Backspace to delete, Esc to clear).
- Responsive layout with larger, touch-friendly buttons for mobile.
- Trigonometric functions operate in degrees.

How to use
1. Open `index.html` in a browser (double-click or serve via a static server).
2. Use the on-screen buttons or the keyboard to enter expressions.
3. Press Enter or the = button to evaluate.

Examples
- `sin(30)` → 0.5
- `2^8` → 256
- `5!` → 120
- `(50+25)%` → 0.75
